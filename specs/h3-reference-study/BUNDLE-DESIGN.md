# H3 release reproduction closure

The ordinary package release archive includes canonical source/configuration,
Lean resources and its accepted native/Python/browser/render evidence. It does
not currently include the frozen study producers, prerequisite records,
parameter export, final proof reviews or synthetic arrays. That archive alone
cannot satisfy the frozen H3.7 reproduction requirement.

The H3 study archive must retain an independently accepted package archive and
an explicit study closure. It must not weaken the package archive validator or
promote missing scientific evidence into readiness. Before assembly, validate
the package archive against the final checkout, the frozen protocol, the actual
native export and proof reviews, and the retained accepted or failed synthetic
attempt. A failed primary result remains a failed result with its controls;
only the corresponding narrowed claim matrix may proceed to review.

The explicit closure includes:

- All three study producers, immutable protocol/freeze and their actual referenced
  pre-outcome review/G0/historical source-map records.
- The native export attempt: exact probe, all compiler/build/identity streams,
  export and accepted attempt record; current native axiom receipt; proof-role
  map and all three independently approving proof review artifacts.
- The complete synthetic attempt, every referenced array and its exact hash,
  acceptance/failure record, all recovery/calibration/control statistics and
  retained failed diagnostics.
- The final claim matrix and its independent Lean/domain/statistical review
  artifacts, with empirical-unavailable and physical nonidentification rows.
- The Python/NumPy runtime and lock requirements, exact invocation, one locked
  deterministic fixture and both setting/control reproduction commands.

All references must remain relative to the declared project. Discover closure
only through typed receipt references and exact declared rosters; never sweep
the repository, unrelated worktrees, provider configuration or user state.
Reject symlinks, nonregular members, traversal, missing/duplicate/undeclared
members, contradictory overlapping bytes, source/receipt changes and altered
arrays. Retain rejected assembly attempts. Bound child commands and input sizes;
use owned atomic output records and deterministic archive metadata.

Validation checks the complete single gzip stream, CRC and exact tar ending.
It reconstructs the full analysis from all 42 retained numerical arrays; an
abbreviated receipt with arbitrary gates cannot establish completeness. Owned
source snapshots bracket reproduction children, and assembly/reproduction
recheck the archive, receipt bytes, streams and output ownership after sealing.

Two independently assembled archives must have identical bytes and pass a
separate read-only validator against final source. A fresh reviewer extracts
into a new directory, validates the contained package archive, installs the
locked validator runtime outside the checkout, reproduces one exact fixture
and both preregistered settings/control evaluation without changing seeds or
thresholds, and compares all declared arrays/statistics. The reproduction
receipt binds archive hash, producer hashes, runtime identity and exact command
results. It establishes synthetic reproduction only.

The slice-local implementation is `bundle_study.py`, with prospective
archive/custody controls in `tests/test_h3_study_bundle.py`. Its input descriptor
has schema version 1 and kind `h3-study-bundle-inputs`, six typed path/hash
references named `package`, `export`, `audit`, `proof_review`,
`synthetic_attempt` and `claim_matrix`, plus three `final_reviews`. A current
claim matrix and its independently written reviews are required inputs;
the assembler does not manufacture approval or scientific outcomes.

The terminal observation remains open. No current H3 archive,
scientific result, final claim review or reproduction acceptance is recorded
here. Publication and licensed empirical execution retain their separate gates.
